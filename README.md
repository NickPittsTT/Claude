Monster Kitchen

This was a game developed using Kimi AI for game idea and initial code, Qwen Code for foundation and Claude Code for bug issues and further development. 
It was created with the idea of assisting my children with a fun way of learning school topics. Their end of term test papers were used as a general guide/principle for Claude Code to build the code from.
My role was that of prompting and guiding the AI model to create the output that I required.
